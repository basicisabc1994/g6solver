# Connect agents, integrations and physical adapters.

Component families: `agents`, `jobs`, `deploy`, `integrations`, `embodied`.

Use `g6_describe("automation")` for registered operations and call templates. Read the named component with
`g6_describe` before choosing fields. Read `g6_describe("g6_invoke")` before invoking an operation.
The list is guidance, never admission to a sensitive operation or consent to share a source.
