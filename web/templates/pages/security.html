Security

An AI agent that can run commands, change files or spend money can do real harm, and an AI system that improves itself must never be able to switch off the checks on it. G6 is built around both risks.

G6 runs on your own computer. It is a library and an MCP server you install yourself. There is no G6 service, account or server of ours behind it, so nothing you do with G6 reaches us.

What G6 does to protect you

  • The MCP server opens no network port. It talks to your agent over standard input and output on your computer. An operation a component marks as sensitive, because it runs a program on your computer, reaches the network or changes your machine, is refused over MCP unless the person who runs the server lists it in G6_MCP_SENSITIVE.
  • The meta-harness changes nothing on its own. It proposes a change, tests it on held-out tasks, and waits for a person to approve it.
  • A bundle's page is served only to your computer (127.0.0.1). It refuses requests from other websites, and its controls need a random token made fresh each time the bundle starts.
  • A model provider's key stays on your computer. G6 reads a key only from your key file, ~/.g6/.env: a plain text file, not encrypted, that you write yourself. A bundle's page never takes a key, and G6 sends a key only to its provider. Delete its line to remove it.

What G6 is not

G6 is not a security boundary on its own: do not use it as the only check in front of something that acts in the real world (see the FAQ). On Windows, once you have run the one-time access grant that g6 doctor prints, the code it runs for you runs in an AppContainer: no network, and only its own run folder writable. Where no operating-system backend confines it (Linux and macOS today, and Windows before the one-time access grant), untrusted code that G6 runs for you (a patch, a generated script, a repository's tests) has your own rights: it can read your key file ~/.g6/.env and your other files, and its network guard works inside Python only. You are responsible for what you run. G6 is open-source software provided "as is", without warranty, under the Apache License 2.0.
