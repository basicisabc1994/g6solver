Components

AI agents fail in the same few ways, again and again. Some 250 million tokens of their reasoning and failure traces were reviewed by hand to find the primitives that close those failures: a periodic table of intelligence{% if show_planned %}, filled in one element at a time{% endif %}.

The components are one of G6's two parts: a prebuilt library of AI primitives for capability extension and failure engineering. Each extends what a model can do or closes one way it fails, and they stack like slices of Swiss cheese: where one slice has a hole, the next one catches the failure. The other part, the meta-harness, learns which of them your work needs, so the system you already run debugs, corrects and improves itself.

Three ways to use them

All three work today, on your own computer.

As built

The core harness as shipped. Connect it to your agent over MCP and every result comes back labelled with what its evidence supports.

Compose

Your agent finds the components a task needs and combines them: g6_find, g6_describe and g6_invoke over MCP, or plain imports in Python.

Full source

Every line is open. Read it, change it, and build your own components on it.

Three modes of work

How G6 runs a job: once, continuously, or before anything starts.

Mission

One piece of work against a frozen standard of done. A person confirms the standard, G6 runs the checks, and the certificate states exactly what the evidence supports.

g6.workforce

Venture

An ongoing operation, run in budgeted ticks. Every outward action is drafted, gated and queued for a person to approve.

g6.operator

Premortem

Before work starts, assume it has already failed and name how. Each of the {{ premortem_modes|length }} failure modes comes with the guard that catches it.

g6.reliability_pipeline

A capability extension harness

A language model predicts text. Extensions give the model you already run senses, memory, tools and a body, so it can do more of a job on its own, and each new ability arrives with checks for the ways it fails.

The model stays yours: a free local model through Ollama, or Anthropic, OpenAI or OpenRouter, through g6.core.llm. The llm_router extension picks a model for each kind of task, local first, and falls back only along a chain you set. What changes is what it can reach. Each group below says what a model cannot do alone, what you can achieve once it can, and which parts of G6 do the work.
