Failure modes

A language model fails in ways built into how it works, so no single check catches every failure. G6 stacks its components like slices of Swiss cheese: each one names the failures it guards against, and where one slice has a hole, the next one catches what slips through.

This is the map of those slices: every failure mode G6 names, the components that guard against it today, and the ones whose own use can cause it. It is generated from the code, so a component appears here only when its package declares the mode.
