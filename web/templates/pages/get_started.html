Get started

G6 works with the AI you already run, so there is nothing to replace. Add it, and your agent can check its own work, gate its actions and engineer itself to your task.

Three ways to use G6, all on your own computer: from your agent, in your code, or as an app.

From your agent

Your agent calls G6's tools through its MCP server.

  1. Install

    Until the first release, install from a copy of the code.

    git clone https://github.com/basicisabc1994/g6solver && cd g6solver pip install ".[mcp]"
    {% comment %}CORE_SANDBOX-01 (owner ruling, 2026-10-27: refused without a boundary unless the person allows it once): g6.core.confine's UNCONFINED_WARNING, word for word, as the README, g6 doctor and the sensitive-op help say it.{% endcomment %}

    Where no operating-system boundary can confine it (macOS, Linux without bubblewrap, and Windows before the one-time access grant), G6 refuses to run untrusted code for you (a patch, a generated script, a repository's tests) unless you allow it once with g6 setup. Code you allow then has your own rights: it can read your key file ~/.g6/.env and your other files, and its network guard works inside Python only. You are responsible for what you run. g6 doctor says whether that code runs confined on your computer: on Linux, install the bubblewrap package for the boundary; on Windows, it prints the one-time commands that grant the access. Then run g6 setup once yourself, not your agent: where your computer has no boundary, it asks whether G6 may run such code without one.

  3. Teach your agent to use G6

    The using-g6 skill tells your agent which G6 step to take at each point of its work. Run this in your project to copy it into .claude/skills, where Claude Code finds it; add --user to have it in every project. For another agent, copy that folder to wherever it reads skills.

    g6 skills install

    For a coding agent, add the superpowers skills for the whole software lifecycle, which G6 ships with credit to their author (unless you already use the superpowers plugin):

    g6 skills install --with-superpowers

    g6 skills list shows every skill, including each component's own.

  4. Check it works

    Ask your agent which G6 tools it can see. It should list g6_find, g6_describe and g6_invoke, and the meta-harness tools.

In your code

Import one component into your own app, or tune a whole task with the meta-harness.

pip install . python -c "from g6.metaharness import adapt"

Where G6 itself calls a model, it uses the one you choose. Put these lines in your key file, .env in G6's folder (~/.g6/.env, or %USERPROFILE%\.g6\.env on Windows): a plain text file you create and only you edit. G6 reads keys only from that file, never from your shell or your agent's settings, so a key there is your go-ahead for G6 to use it. A paid provider uses your own account; G6 never picks one for you.
