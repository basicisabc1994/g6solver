# v0.3.0 known limits

Every row is a finding an independent reviewer reproduced on G6's own code, with a test that shows it. None is a
must-close finding: each fails in the safe direction (G6 refuses, withholds or reports less), needs code already
running in G6's own process, is a narrow platform edge that ends in an error, is a narrowed race, or needs a
certificate-bound file. Must-close findings are closed on this line, or stay out of 0.3.0 with their code (listed
at the end). The machine-readable list, with every row's evidence and follow-up, is `v0.3.0-ledger.tsv`.

141 limits in 30 changes. "A repair is on the line" means a later repair touched the code; the
finding is listed until a fresh review re-runs its test.
